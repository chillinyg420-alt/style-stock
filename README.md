# 스타일별 재고·판매현황 추출기 v6

ERP 원본 엑셀을 넣으면 **점×스타일×컬러**별 재고·판매·창고·입고년월·판매가를 채운 엑셀(`YYMMDD_스타일별재고및판매현황.xlsx`)을 내려받는 단일 HTML 도구. 파일은 브라우저 안에서만 처리(서버 전송 없음).

## 배포
- 주소: https://chillinyg420-alt.github.io/style-stock/ (`index.html` + `robots.txt`, 검색 차단: meta noindex + robots.txt)
- 수정 후 화면이 안 바뀌면 Ctrl+F5(강력 새로고침)
- 인터넷 없이 HTML 파일을 PC에서 바로 열어도 동작(SheetJS 내장)

## 입력 파일 (점재고 필수, 나머지 선택, 자동 인식)
| 종류 | 인식 기준(헤더) | 채우는 열 |
|---|---|---|
| 점재고 — 스타일별 입출고실적조회 | `점`·`사이즈`·`현재재고` | 결과 행 기준, 합계, 사이즈별 재고, 브랜드, 상품 |
| 창고재고 — 스타일별 입출고실적조회 | `창고`·`사이즈`·`현재재고` | 창고 (스타일+컬러 현재재고 합) |
| 스타일별 판매현황상세 | `수량(합계)` 또는 `정상매출일자` | 판매수량 (점+스타일+컬러 `수량(합계)` 합), 중분류 |
| 사이즈별 현재고 조회 | `최종입고일` | 년·월, 중분류. 매장은 상단 조회조건 줄에서 읽음 |
| Shoe Card 출력 | `감가율`·`판매가` | 정상가·판매가·감가율 (스타일+컬러, 자사스타일 보조) |

헤더 행 = 상단 40행 안에서 `스타일`을 포함하고 값이 5개 이상인 첫 행. ERP 파일은 선언 범위가 실제보다 작아 셀 전수 스캔으로 범위를 보정(`fixRange`).

## 결과 규칙
- 서식(원본 양식 261117과 동일 색 구성): 제목행 열 묶음별 색(점~컬러 진한 파랑 · 판매수량 초록 · 창고 황토 · 합계 갈색 · 사이즈 주황), 데이터 점~중분류 회색 · 브랜드~컬러 연하늘 · 판매수량 연초록 · 창고 황토 · 합계 살구 · 사이즈 진회색+흰 글씨, Noto Sans KR 10pt 굵게, 흰 테두리, 틀 고정(사이즈 첫 열·3행), 정상가·판매가 천 단위 쉼표(`#,##0`), 조건부 서식: 사이즈 영역 빈 칸 연노랑 `#FFE699`(원본 양식 규칙 `LEN(TRIM())=0`과 동일)
- 양식: A열 비움 · 1행 열별 합계(판매수량·합계·사이즈. 창고는 매장별 중복이라 제외) · 2행 제목 · 3행~ 데이터 · 자동필터
- 열: 점, 년, 월, 중분류, 브랜드, 상품, 스타일, 컬러, [정상가, 판매가, 감가율 — Shoe Card 있을 때만], 판매수량, 창고, 합계, 사이즈(문자순)
- **기준 = 점재고.** 결과 행은 점재고 파일에 있는 점·스타일·컬러로만 만듦. 판매·창고·입고년월·가격은 그 행에 값을 채우는 용도로만 사용(점재고에 없는 판매 등은 행 생성 안 함, 화면에 제외 건수 표시)
- 점재고에 있어도 현재재고 0 + 판매 없음 행은 제외
- 출력 범위(선택): 감가율·판매수량·재고(합계) 최소~최대, 모두 만족(AND)하는 행만 출력. 판매 빈칸=0, 감가율 조건 시 Shoe Card 없는 행 제외. 남은 행에 없는 사이즈 열은 뺌. 파일명에 조건 표기(예: `_감가30↑_판매0↓_재고5↑`)
- 빠른 버튼: 전체 · 부진재고(판매≤0·재고≥5) · 고감가(감가율≥50) · 고감가 부진(감가율≥50·판매≤0) · 정상가(감가율 0) · 판매 2개↑ · 재고 1~2개
- 정렬(매장 구분 없이 전체): 판매수량↓ → 재고합계↑ → 감가율↑ → 컬러 → 스타일 → 상품 → 브랜드 (판매 빈칸=0, 감가율 빈칸은 맨 뒤)
- 매칭 키: 스타일·컬러 (대문자·공백 정규화). '합계' 행 제외
- 입고년월: 같은 매장 파일 우선 → 없으면 업로드된 현재고조회 중 최신 최종입고일
- 점재고 파일이 없으면 만들지 않고 안내 문구 표시
